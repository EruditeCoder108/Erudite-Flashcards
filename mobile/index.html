Help & Import Format

Import file

Use the Creator screen's Import file button for new card content. Full backups still use Import Backup.

TXT

Uses your separator settings. Default format:

example.txt 
term1;definition1@term2;definition2

CSV / TSV

Use spreadsheet columns. Headers are optional. Recognized headers: term, definition, tags, reverse, type.

cards.csv 
term,definition,tags,reverse
Newton's law,"\(F = ma\)","physics,forces",true

JSON

Use JSON for rich cards, reverse cards, cloze cards, tags, image occlusion, and HTML/CSS cards. JSON imports content only; backups are for SRS history and full app restore.

deck.json 
{
  "version": 1,
  "name": "Physics formulas",
  "className": "Class 10 Science",
  "cards": [
    {
      "type": "basic",
      "term": "Newton's second law",
      "definition": "\\(F = ma\\)",
      "tags": ["physics", "forces"]
    },
    {
      "type": "basic",
      "term": "Derivative of x^2",
      "definition": "\\(2x\\)",
      "reverse": true
    },
    {
      "type": "cloze",
      "text": "The SI unit of force is {{c1::newton}}."
    },
    {
      "type": "image-occlusion",
      "term": "Cell diagram",
      "image": { "dataUrl": "data:image/png;base64,..." },
      "occlusion": {
        "masks": [
          { "shape": "rect", "x": 0.12, "y": 0.2, "w": 0.25, "h": 0.1, "answer": "Nucleus" }
        ]
      }
    },
    {
      "type": "advanced-html",
      "term": "Projectile motion",
      "definition": "Formula card",
      "advancedHtml": {
        "frontHtml": "<div class=\"card-design\"><h2>Projectile Motion</h2></div>",
        "frontCss": ".card-design{width:340px;min-height:470px;padding:18px;background:white;color:#111}",
        "backHtml": "<div class=\"card-design\"><p>Range: \\(R = v^2\\sin(2\\theta)/g\\)</p></div>",
        "backCss": ".card-design{width:340px;min-height:470px;padding:18px;background:white;color:#111}"
      }
    }
  ]
}

ZIP package

Use .zip for image-heavy decks. It must contain one deck.json plus a media/ folder.

structure.txt 
evolution.zip
  deck.json
  media/
    fig_miller_experiment.webp
    fig_homologous_organs.webp

Inside deck.json, reference files like this:

deck.json (ZIP version) 
{
  "version": 1,
  "name": "Evolution",
  "cards": [
    {
      "type": "basic",
      "term": "<img src=\"media/fig_miller_experiment.webp\" alt=\"Miller experiment\">",
      "definition": "Explain the Miller-Urey experiment."
    }
  ]
}

Keep media local to the package. Use paths like media/file.webp; avoid external URLs and giant Base64 strings.

JSON Deck Generator

Generates a complete deck import file (JSON format) with support for basic, cloze, occlusion, HTML cards, tags, and reverses.

ZIP Package Generator

Generates a structured ZIP package containing media files (images/audio) and a reference mapping deck.json file.

HTML & CSS Card Creator

Generates a single custom card with styled HTML layout, responsive CSS canvas, math formula rendering, and no JavaScript.

Safe rich text

Allowed rich text tags and styles: bold, italic, underline, lists, blockquote, code, pre, horizontal rules, highlight marks, custom text colors (via SPAN inline styles), and LaTeX math syntax with \(...\) or \[...\].

HTML/CSS cards

The custom HTML canvas is exactly 340px wide, 470px tall, and 20px rounded. Use HTML and CSS only. No JavaScript, scripts, iframes, forms, external URL dependencies, or fixed overlays.

Image occlusion

Use normalized mask coordinates from 0 to 1 relative to image dimensions. Each mask becomes one study card. JSON accepts data URL images; ZIP packages can reference images from media/.

Anki packages

Direct .apkg import support is planned for future versions. Currently, Anki packages must be imported using their media file paths or by converting to CSV/TXT format.
