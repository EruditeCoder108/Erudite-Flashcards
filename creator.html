Import & Export Help

Export Set

Export your flashcard set as a JSON file that can be shared or backed up.

What gets exported:

  • Set name and all cards
  • Text content (terms and definitions)
  • Images (as base64 data)
  • Export timestamp

File format:

JSON file with the following structure:

{
  "name": "My Flashcard Set",
  "cards": [
    {
      "term": "Question text",
      "definition": "Answer text",
      "termImage": "data:image/...",
      "definitionImage": "data:image/..."
    }
  ],
  "exportDate": 1234567890
}

Import Set

Import a previously exported flashcard set from a JSON file.

Requirements:

  • File must be in JSON format
  • Must contain a "cards" array
  • Each card should have "term" and "definition" fields
  • Images are optional but supported

What happens when importing:

  • Current set content is replaced
  • Set name is updated from the file
  • All cards are recreated with their content
  • Images are restored if present

Tips

  • Use export to backup your sets regularly
  • Share sets with others by sending the JSON file
  • Import works with sets from other users
  • Large sets with many images may create large files
