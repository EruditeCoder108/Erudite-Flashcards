Flashcards Logo Complete Package
================================

This package contains the final 3D flashcards logo with the magenta background removed and exports ready for Android, web, and favicons.

Folder guide
------------
master/
  - flashcards-logo-3d-source-magenta.png      Original render with chroma-key background
  - flashcards-logo-3d-transparent-1024.png    Master transparent PNG

png/
  - Transparent PNG exports in these sizes:
    16, 32, 48, 64, 72, 96, 114, 120, 128, 144, 150, 152, 167, 180, 192, 256, 384, 512, 1024

webp/
  - Transparent WebP exports: 192, 512, 1024

android/
  - ic_launcher-mdpi.png      48x48
  - ic_launcher-hdpi.png      72x72
  - ic_launcher-xhdpi.png     96x96
  - ic_launcher-xxhdpi.png    144x144
  - ic_launcher-xxxhdpi.png   192x192
  - pwa-192.png               192x192
  - pwa-512.png               512x512
  - play-store-512.png        512x512
  - maskable-384.png          384x384
  - maskable-512.png          512x512

web/
  - favicon.ico
  - favicon-16x16.png
  - favicon-32x32.png
  - favicon-48x48.png
  - apple-touch-icon.png      180x180
  - android-chrome-192x192.png
  - android-chrome-512x512.png
  - mstile-150x150.png
  - icon-192.png
  - icon-512.png
  - site.webmanifest

favicon/
  - favicon.ico plus PNG favicon sizes 16/32/48/64

Recommended usage
-----------------
- Play Store / app icon: android/play-store-512.png
- Android launcher icons: android/ic_launcher-*.png
- Website favicon: web/favicon.ico
- Apple touch icon: web/apple-touch-icon.png
- PWA manifest: web/site.webmanifest + web/android-chrome-192x192.png + web/android-chrome-512x512.png
- General transparent master: master/flashcards-logo-3d-transparent-1024.png
